# v28 — visual interaction

- Android DownloadManager handles update APK downloads; the browser is no longer the update transport.
- Pinch to zoom the board up to 2.65x; drag to pan while zoomed.
- Double tap the board to return to Fit-to-screen.
- Long press a cell to dim unrelated cells and inspect the local equation neighborhood; tap empty board space to leave local focus.
- Candidate drawer handle cycles through hidden, working, and expanded states; dragging still gives continuous control.
- All view gestures are kept separate from mathematical input and are recorded as lightweight trace events.
