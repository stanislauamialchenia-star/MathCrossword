# MathCrossword v27 — visual cleanup

- Update check is no longer a full-size home action. It is a compact refresh icon in the bottom app-information footer.
- Version/offline/local-data information is grouped into that footer so the primary menu stays focused on play.
- After solving, the candidate drawer is replaced by a reserved completion sheet. “Готово” and “Следующий уровень” no longer float over or cover the crossword.
- The completed board recalculates against the reserved sheet height, so the whole puzzle remains visible.
